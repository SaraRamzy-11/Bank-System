# Bank System

A console-based Bank Management System built with C++ as part of the ProgrammingAdvices OOP as it Should Be (Applications) course.

## About the Project

This project is a practical application of Object-Oriented Programming concepts in C++.

It includes different parts of a banking system such as managing clients and users, transactions, money transfers, and currency exchange.

The project was developed and organized as part of my learning journey with ProgrammingAdvices.

## Features

- User login and access permissions
- Client management
- Add, update, delete, and find clients
- Deposit and withdrawal operations
- Money transfers between clients
- Transfer history
- Total balances
- User management
- Login register
- Currency exchange
- Find currencies
- Update currency rates
- Currency calculator

## OOP Concepts

The project applies several Object-Oriented Programming concepts, including:

- Classes and Objects
- Encapsulation
- Inheritance
- Abstraction
- Polymorphism
- Interfaces
- Constructors and Destructors
- Static Members
- Access Modifiers
- Reusable Utility Classes
